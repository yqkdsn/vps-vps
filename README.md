## 先分清香港VPS的三档线路，不然测评数字看不懂

香港 VPS 的线路大致能分三档，价格基本跟档位走。

**对大陆优化的精品线路**。电信走 CN2 GIA（59.43 开头的骨干），联通走 AS4837 或 AS9929，移动走 CMI。这一档的典型表现是大陆三网平均延迟落在 40–60ms，晚高峰波动小。代价是贵，而且带宽通常给得保守。

**移动优化但电信联通一般**。移动双程 CMI 直连，体验很好；电信和联通去程绕日本、回程直连。延迟数字看起来还行，但电信用户晚高峰得有心理准备。

**纯国际线路**。接的是 IIJ、NTT、RETN 这类国际骨干，对大陆没有专门优化，欧洲方向的延迟反而更漂亮。适合面向海外用户的业务——如果你主要访客在国内，买这一档大概率会后悔。

雨云的香港节点正好横跨了这三档，这也是它值得单独拿出来测评的原因。

## 雨云是谁，香港有几个节点

雨云成立于 2018 年，是持自主知识产权的国产云计算服务商，主营云服务器、裸金属服务器、虚拟主机、游戏云、对象存储和 CDN 等产品，持有工信部颁发的 ISP、IDC、CDN 相关许可证。它和几个大厂的区别很直接：香港、美国节点不用备案，价格门槛低，控制台自带宝塔、1Panel、Docker、OpenList 等预装镜像，开通后基本不用折腾环境。

香港这边，雨云按区和线路分了好几套产品：

- **香港三区**：精品三网直连（CN2 + CMI + CUG），AMD EPYC 7702 平台，定位是延迟优先
- **香港二区**：移动 CMI 优化、三网直连，带宽给得比三区大
- **香港四区**：IIJ 大带宽混合软银线路，Xeon Gold + 企业级 NVMe
- **香港五区**：国际大带宽型号，标称最高 1Gbps，自带香港原生 IP，可选 300G+ 高防 IP

一个提醒：这些区的库存和线路会随上新调整，某一段时间二区缺货、某一段时间五区上线新档，都是常态。

## 第三方测评里，这些数据值得记一下

下面这些数字来自公开发表的测评文章和雨云官方论坛的实测帖，我按线路整理，方便对照。

**延迟**。对大陆优化的那几个区，全国三网平均延迟普遍在 45ms 上下，分运营商看，电信约 44ms、联通约 38ms、移动约 53ms，基本没有丢包。另一份针对二区的测评测出平均约 56ms，最快的上海电信节点约 32ms。香港四区走 IIJ 混合线路，三网平均延迟约 95.3ms，最快节点约 63ms，去程直连、回程绕日本。五区是纯国际线路，三网平均延迟约 139ms，上海移动最好时约 34ms，电信和联通存在明显绕路。

**性能跑分**。香港二区 2 核 2G 机型，LemonBench 单核约 1597、多核约 3123，Geekbench 6 单核约 1126、多核约 2052。五区 2 核 2G 机型，Geekbench 6 单核约 1070、多核约 1891，UnixBench 单核约 1218、多核约 2671。多线程倍率接近核心数的两倍，说明 CPU 分配相对真实，没有明显的严重超售迹象。

**带宽**。五区大带宽型号实测下载峰值约 486Mbps、上传约 365Mbps，接近标称值。三区那类精品线路带宽只有 10–50Mbps，胜在稳定而不是快。

**解锁和 IP 质量**。香港二区实测可解锁 Netflix 港区、Disney+、YouTube 港区，TikTok 识别为 ALISG 区域，ChatGPT 只有 App 端可用，Spotify 注册受限。五区测评里 TikTok 不可用、ChatGPT 可用。IP 的欺诈分和滥用分都是 0，黑名单记录很少，但类型是数据中心 IP，不是住宅 IP——想靠它扮演"香港本地人"注册敏感账号，指望不上。

## 价格之外，几条真正影响体验的规则

**流量用完不是断网，是限速。** 雨云的规则是流量用尽后限速到 5Mbps，可以额外买流量包恢复高速。更实用的一条是每月用不完的流量可以叠加到下个月，不会按自然月清零——对流量波动大的项目挺友好。但流量包单价各节点口径不一，测评里见过 50 元/200GB 和 20 元/1TB 两种说法，买之前自己核一下。

**"不限流量"和"大带宽"是二选一。** 同一个配置有两个变体：大带宽但限流量，小带宽但不限流量，价格一样。比如 2 核 2G 的不限流量版本，上行带宽只有约 10Mbps，做下载站或大流量转发会很难受。

**IP 要单独算钱。** 套餐自带 1 个 IPv4，额外的 IP 约 5 元/个/月。需要用高防 IP 的话另加，测评里出现过香港节点约 30–40 元/月的口径。默认套餐不带 DDoS 防御。

**硬盘默认 30GB，可弹性扩容。** 固态约 0.4 元/GB/月，高效云盘约 0.1 元/GB/月。系统装完、日志攒一攒，30GB 其实不太经用，长期跑的项目建议一开始就把盘算进去。

**邮件端口大多封闭。** 多份测评都测出 SMTP 端口被封、SMTPS 部分可用。想拿它做邮件服务器或营销邮件群发，方向就不对。

**关于代理用途。** 有测评提到雨云的云服务器不允许用来搭建代理类服务。如果你的业务沾这条，下单前先找客服确认，别等买完才发现。

## 不同需求怎么对号入座

**个人博客、企业展示站、WordPress 小站**：香港三区 1 核 1G 或 2 核 2G 就够。走的是精品三网线路，国内访问延迟稳定在 50ms 左右，带宽小一点但够用。

**外贸独立站、面向东南亚或欧洲的业务**：优先看香港四区 IIJ 或五区国际线路。五区自带原生 IP，欧洲方向延迟低；四区 20Mbps 带宽 + 1TB 流量，43 元的档位性价比不错。前提是你的访客主要不在大陆。

**API 中转、爬虫调度、下载分发**：五区的大带宽档更合适，500Mbps 到 1Gbps 的端口能跑起来，1TB 月流量加上流量叠加机制，短期峰值不至于被掐。别选不限流量的小带宽版本。

**流媒体和解锁需求**：香港二区在测评里表现最好，Netflix 港区、Disney+、YouTube 港区都能解；五区 TikTok 不可用，这一点要提前知道。

**预算极紧、只想先跑通环境**：1 核 1G 入门档，配合首月 5 折券和 1 元试用，试错成本很低。

**不建议的场景**：邮件服务器、需要住宅 IP 的业务、依赖 TikTok 的场景、以及要求 DDoS 防御的生产业务——后者记得单独加高防 IP。

## 常见问题

**香港节点需要备案吗？** 不需要。香港机房不在备案要求范围内，这也是它常被用来放个人站点的原因。

**2 核 2G 能跑 WordPress 吗？** 能跑，装了宝塔或 1Panel 之后还剩得下一些空间。但内存不宽裕，插件装多了容易吃紧，有预算直接上 2 核 4G。

**晚高峰会不会掉速？** 走精品三网线路的那几个区，测评里的晚高峰表现比较稳，有测出延迟基本稳在 50ms 以内。走纯国际线路的五区，电信和联通绕路明显，晚高峰会更明显。

**香港二区还能买吗？** 部分测评写作时二区处于缺货状态，建议直接去购买页看当前可售机房，缺货就换三区或五区。
